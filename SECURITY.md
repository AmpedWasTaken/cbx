# Security Policy

## Supported versions

CBX is currently pre-release software. Security fixes land on the latest development branch until the first stable release.

## Reporting a vulnerability

Please avoid publishing a security issue with exploit details before it can be reviewed.

Open a private GitHub security advisory for this repository when available, or contact the repository owner through their published GitHub contact method.

Useful details include:

- affected CBX version or commit
- operating system
- reproduction steps
- impact
- suggested mitigation, if known

## Project boundary

CBX is designed as a one-way callback/canary collector for authorized testing. Security reports involving unintended secret collection, unsafe command execution, tunnel exposure, path traversal, callback-token guessing, or sensitive-data persistence are especially useful.
